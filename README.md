# WePlay для Samsung Tizen

WePlay — приложение для Samsung TV с Tizen 5.5 и новее. Интерфейс, встроенный плеер и поддержка пульта работают в установленном приложении.

## Установка на телевизор

Пошаговая инструкция: [установка WePlay на Samsung Tizen](docs/INSTALL.md). В ней описаны Developer Mode, Host PC IP, сертификаты, сборка и установка `.wgt`, добавление на главный экран и последующие обновления без компьютера.

## Обновления

После однократной установки `.wgt` с загрузчиком приложение проверяет `updates/stable.json`, скачивает подписанную новую версию и сохраняет её на телевизоре. Когда новая версия готова, рядом с «Поддержать» появляется светлая кнопка «Доступна новая версия» с иконкой обновления и цветным анимированным свечением. По нажатию откроется окно с номером версии и кнопками «Обновить сейчас» и «Позже». Новая версия также запускается при следующем открытии WePlay. Свечение у кнопки «Поддержать» убрано. Во время просмотра видео обновления не скачиваются и не применяются.

При недоступном интернете запускается последняя сохранённая версия или комплектная версия приложения. Обновление с неверной подписью или повреждёнными файлами отклоняется. Если новая версия не запускается, загрузчик возвращается к предыдущей рабочей версии. История просмотра и избранное хранятся отдельно.

Обновления интерфейса и логики не меняют разрешения Tizen, системную иконку, подпись `.wgt` и сам загрузчик. Такие изменения требуют установки нового `.wgt`.

### Публикация новой версии

Нужен Node.js 18 или новее. Отредактируйте файлы `app/`, затем выполните:

```sh
node tools/build-update.cjs --source app --version 1.22.31 --key /безопасный/путь/author-key.pem --out updates
```

У каждой версии свой неизменяемый каталог `updates/releases/<версия>/`. Сначала создаются файлы выпуска, затем обновляется указатель `updates/stable.json`. Закоммитьте весь каталог `updates/` одним коммитом и отправьте его в `main`. GitHub может некоторое время кешировать старый указатель; клиент продолжает работать на текущей версии.

Для проверки сборки без закрытого ключа:

```sh
node tools/build-update.cjs --source app --version 1.22.31 --check
```

Закрытый ключ подписи хранится вне репозитория. В приложение встроен только открытый ключ. При потере закрытого ключа потребуется новая `.wgt` с новым открытым ключом. Не публикуйте ключ, сертификаты, `settings.js`, пароли и токены в GitHub. Если настроена сборка в CI, передавайте ключ только через защищённое хранилище секретов.

### Сборка установочного пакета

Создайте локальный `app/settings.js` по образцу `app/settings.example.js`, сохраните используемые настройки и задайте версию в `config.xml` и `update-config.js`. Затем обновите резервный интерфейс:

```sh
node tools/build-shell.cjs app
```

Подпишите приложение своим авторским сертификатом Tizen. Для обновления существующей установки используйте прежние идентификаторы приложения и тот же авторский сертификат. Сертификаты и готовые пакеты с личными настройками в этом репозитории не хранятся.

## Изображения и данные

Для сериалов и мультсериалов основной источник больших фонов и фотографий актёров — [TVmaze](https://www.tvmaze.com/api). Данные TVmaze используются по CC BY-SA с указанием источника в интерфейсе. При отсутствии промофона используются TMDB/Cinemeta; для фильмов они остаются основными. Уменьшенные постеры могут загружаться из Кинопоиска и источников каталога.

Библиотека HLS.js распространяется по Apache-2.0; текст лицензии находится в `app/vendor/HLS-LICENSE.txt`. Лицензии и права на материалы внешних сервисов сохраняются за их правообладателями.
