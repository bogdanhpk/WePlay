## Обновления

После однократной установки `.wgt` с загрузчиком приложение проверяет `updates/stable.json`, скачивает подписанную новую версию и сохраняет её на телевизоре. Когда новая версия готова, рядом с «Поддержать» появляется светлая кнопка «Доступна новая версия» с иконкой скачивания и цветным анимированным свечением. По нажатию откроется окно с номером версии и кнопками «Обновить сейчас» и «Позже». Новая версия также запускается при следующем открытии WePlay. Свечение у кнопки «Поддержать» убрано. Во время просмотра видео обновления не скачиваются и не применяются.

При недоступном интернете запускается последняя сохранённая версия или комплектная версия приложения. Обновление с неверной подписью или повреждёнными файлами отклоняется. Если новая версия не запускается, загрузчик возвращается к предыдущей рабочей версии. История просмотра и избранное хранятся отдельно.

Обновления интерфейса и логики не меняют разрешения Tizen, системную иконку, подпись `.wgt` и сам загрузчик. Такие изменения требуют установки нового `.wgt`.
