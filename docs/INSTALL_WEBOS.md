# Как установить WePlay на LG webOS

Нужен телевизор LG с **webOS TV 5.0 или новее**. Подключите компьютер и телевизор к одной домашней сети. После установки компьютер можно выключить. Для каталога, видео и обновлений телевизору нужен интернет.

## 1. Скачайте WePlay и Node.js

- [Скачать установочный пакет WePlay 1.0.3 для LG (.ipk)](https://github.com/bogdanhpk/WePlay/raw/refs/heads/main/downloads/app.weplay.tv_1.0.3_all.ipk)
- Если на компьютере ещё нет Node.js, установите версию LTS. [Скачать Node.js](https://nodejs.org/en/download)

## 2. Включите Developer Mode на телевизоре

1. В магазине приложений LG найдите и установите **Developer Mode**.
2. Откройте приложение, войдите в аккаунт LG Developer и включите **Dev Mode Status**. Телевизор перезапустится.
3. Снова откройте **Developer Mode** и включите **Key Server**. Запишите **IP-адрес телевизора** и **Passphrase** — код из шести символов. Оставьте этот экран открытым.

Если аккаунта ещё нет, создайте его через **Sign In** на сайте LG Developer. [Инструкция LG с картинками](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app)

## 3. Установите WePlay с компьютера

Откройте терминал в папке со скачанным IPK. В строке с `host` замените `192.168.1.50` на IP телевизора из Developer Mode.

```sh
npm install -g @webos-tools/cli
ares-setup-device --add lg -i "host=192.168.1.50" -i "port=9922" -i "username=prisoner"
ares-novacom --device lg --getkey
```

Когда терминал попросит `passphrase`, введите код с экрана телевизора. Регистр букв важен. Затем выполните ещё две команды.

```sh
ares-install --device lg app.weplay.tv_1.0.3_all.ipk
ares-launch --device lg app.weplay.tv
```

WePlay откроется на телевизоре. В следующий раз запустите его с главного экрана LG.

## Если установка не получается

- **Компьютер не видит телевизор или не получает ключ.** Проверьте IP, общую сеть и переключатель **Key Server**. Если `lg` уже добавлен и адрес изменился, запустите `ares-setup-device` и выберите **modify**.
- **Терминал не находит IPK.** Откройте терминал в папке со скачанным файлом и проверьте его имя.
- **Заканчивается время Developer Mode.** Откройте **Developer Mode** и нажмите **Extend**, пока в поле **Remain Session** ещё есть время. При отключении режима LG удаляет установленные через него приложения.

## Обновления

Пакет **1.0.3** уже поддерживает обновления из приложения. Когда рядом с **Поддержать** появится **Доступна новая версия**, нажмите её и выберите **Обновить сейчас**. WePlay перезапустится и сохранит историю и избранное.

Если WePlay установлен из пакета **1.0.2** или более раннего, один раз установите IPK **1.0.3** поверх приложения. Для обновления системной иконки или сетевой службы понадобится новый IPK.
