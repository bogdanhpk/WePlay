# Смотреть дальше

Ближе к завершению видео плеер показывает компактную карточку с обложкой и названием. Пока идёт видео, карточка не перехватывает фокус. При скрытом управлении нажмите вниз, чтобы выбрать её; вверх возвращает фокус к шкале времени.

- Следующая серия запускается автоматически через 5 секунд. Если источник передал точный момент начала титров, отсчёт начинается на титрах; иначе — после окончания видео.
- Заполнение фона карточки показывает ход отсчёта. Пауза, открытые настройки, подтверждение выхода и скрытое приложение останавливают переход.
- «Назад» скрывает карточку и отменяет переход для текущей серии. Повторное нажатие возвращает обычное управление плеером.
- Следующая часть фильма запускается только по нажатию. Например, после «Матрицы» предлагается «Матрица: Перезагрузка», когда она найдена в подключённых каталогах.
- Пропущенная или недоступная серия не заменяется более поздней. Когда следующей серии нет, автопереход не запускается.

Порядок частей фильмов берётся из коллекций TMDB и дат выхода. Совпадение проверяется по идентификатору либо точному названию и году. Одноимённые сериалы и ремейки не подставляются. Если продолжение не определено или отсутствует в каталогах, карточка фильма не появляется.

В эту сборку включены данные 34 коллекций и 139 фильмов. Для фильмов вне этого индекса прямой запрос TMDB возможен при наличии личного ключа на устройстве. Личные ключи владельца не включены в публичные установщики. Компьютер для работы карточки не нужен.

## Для разработчика

Обновите публичный индекс командой `node tools/build-collections-index.cjs`, предварительно задав `TMDB_READ_TOKEN` в окружении. Инструмент использует список публичных фильмов из `app/tmdb-index.js` и основные франшизы, сохраняет только открытые данные в `app/collections-index.js`. Ключ в результат не попадает.

Серии могут передавать `creditsStartMs` / `credits_start_ms` или `creditsStartSeconds` / `credits_start_seconds`. Принимается только отметка в заключительной части видео; число без явно заданных единиц не интерпретируется как начало титров.

Проверка выбора продолжения: `node tools/test-next-media.cjs`.
