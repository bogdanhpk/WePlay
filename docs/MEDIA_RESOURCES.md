# Общий слой изображений

Все страницы используют `WePlayArtwork` из `app/artwork.js`. Страницы задают назначение изображения, а выбор источника, резервов и кеширование выполняются внутри слоя.

- `resolve(item, {actors: true})` возвращает общий пакет: `identity`, `images`, `actors` и метаданные.
- `attach(img, item, "backdrop")` подключает большой фон.
- `observe(img, item, "preview")` подключает горизонтальное превью с отложенной загрузкой.
- `observe(img, item, "poster")` подключает вертикальный постер.
- `profile(img, actor)` использует общий реестр фото людей.

Одинаковые медиа объединяются по проверенным внешним ID либо названию, типу и году без конфликтов ID. Запросы объединяются, выбранное семейство обложки сохраняется, размеры загружаются по назначению. Если большой оригинал недоступен, остаётся превью этого же изображения. Неудачные загрузки получают задержку перед повтором, а успешно показанные изображения не меняются посреди просмотра страницы.

Набор источников включает TMDB и его локальный индекс, TVmaze, Cinemeta, проверенные постеры Кинопоиска и изображения каталогов. Ключи API остаются в локальных настройках и не входят в публичные обновления.

В публичную сборку входит индекс горизонтальных обложек для более чем 3 400 медиа. Он дополняет источники START и Wink русскими названиями, российскими и советскими фильмами и сериалами, а также популярными новинками. Эти изображения доступны без API-ключа и поиска по веб-страницам TMDB. Главная, списки и профиль используют одну обложку, загружая подходящий размер. Год, тип медиа и внешние ID проверяются перед подбором; при неоднозначном совпадении чужая обложка не подставляется.

Для обновления индекса владелец сборки может запустить `node tools/build-preview-index.cjs --token-file /путь/к/локальному-tmdb.json`. Файл должен содержать `readToken`. В результат попадают только публичные названия, ID и пути изображений; ключ остаётся на компьютере. Аргумент `--include movie:123` или `--include tv:123` добавляет конкретное проверенное медиа.
