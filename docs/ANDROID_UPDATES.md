# Публикация обновлений Android TV

Начиная с APK 1.0.1, WePlay проверяет `updates/android/stable.json` в этом репозитории. Проверка выполняется при запуске и затем примерно раз в минуту, пока приложение открыто и просмотр не запущен. GitHub может некоторое время отдавать сохранённую версию файла.

Если `versionCode` в Android-канале больше установленного, рядом с «Поддержать» появляется кнопка «Доступна новая версия». APK загружается после нажатия пользователя. Установка завершается через системное подтверждение Android.

Обычный коммит исходников и обновление канала Tizen сами по себе не создают Android-обновление. Нужно собрать новый APK и опубликовать его вместе с описанием.

## Сборка

Исходники Android находятся в [android/](../android/). Нужны Node.js, JDK 17 и Android SDK с Platform 35 и Build Tools 35.0.0.

1. Увеличьте `versionCode` и `versionName` в `android/version.properties`.
2. Соберите release APK:

```sh
cd android
./gradlew assembleRelease
```

Перед сборкой Android-адаптер переносит общий интерфейс из `app/` в ресурсы APK. Личные ключи каталогов не копируются.

3. Подпишите APK **тем же Android-ключом**, которым подписан предыдущий выпуск. Ключ и пароль храните вне репозитория. При смене ключа Android не сможет установить обновление поверх существующего приложения.
4. Проверьте новый APK на тестовом устройстве.

## Подготовка публикации

Из корня репозитория выполните:

```sh
node android/tools/make-update.cjs /path/to/signed-WePlay.apk --out .
```

Скрипт проверит подпись, прочитает версию из APK и подготовит:

- `downloads/WePlay-AndroidTV-<version>.apk`;
- `updates/android/stable.json`;
- новую запись в `downloads/SHA256SUMS.txt`.

Инструмент запрещает заменять APK уже опубликованной версии другим файлом, уменьшать номер версии и менять ключ подписи. Для новой сборки увеличивайте оба номера версии.

Опубликуйте APK, описание канала и контрольные суммы **одним коммитом**. Обновите ссылку на APK в README и инструкции установки. Старые версии APK оставляйте по прежним адресам.

## Проверки перед установкой

Приложение принимает обновления своего пакета с более высоким `versionCode`, совместимой версией Android и тем же сертификатом подписи. Файл проверяется по размеру и SHA256. Повреждённый APK, чужая подпись или несовпадение версии отклоняются.

Скачанный APK сохраняется в закрытой папке приложения. Доступ к файлу получает только системный установщик. История просмотра и избранное при этом не изменяются.

## Тесты

На отдельном эмуляторе или тестовом Android TV:

```sh
cd android
node tools/test-updates.cjs emulator-5556
```

Укажите идентификатор своего тестового устройства. Скрипт создаёт APK следующей тестовой версии и APK с другим временным ключом, затем запускает проверки. Используется отдельный пакет `app.weplay.tv.debug`; production-пакет `app.weplay.tv` не переустанавливается. Временный ключ удаляется после проверки.

Тестовые APK создаются локально и не входят в публикацию. Канал Tizen `updates/stable.json` остаётся отдельным.
