# Установка WePlay на Android TV и Google TV

Нужен телевизор или приставка с Android TV / Google TV 8.0 и новее и установленным Android System WebView. Версия 1.0.4 работает без компьютера; для каталогов и просмотра нужен интернет.

[Скачать WePlay 1.0.4 — APK](https://github.com/bogdanhpk/WePlay/raw/refs/heads/main/downloads/WePlay-AndroidTV-1.0.4.apk) · [Контрольные суммы](../downloads/SHA256SUMS.txt)

## Установка

1. Передайте APK на телевизор или приставку через USB или приложение для передачи файлов.
2. Откройте файл в файловом менеджере телевизора.
3. Если Android запросит разрешение на установку из этого приложения, разрешите её.
4. Нажмите «Установить», затем откройте WePlay в списке приложений.

APK предназначен для Android TV и Google TV. Для Samsung с Tizen используйте [установщик WGT и инструкцию для Samsung](INSTALL.md).

## Управление

- Стрелки пульта перемещают фокус между карточками и кнопками.
- OK выбирает элемент, запускает просмотр или ставит видео на паузу.
- «Назад» закрывает панель или возвращает на предыдущую страницу. При выходе из просмотра появляется подтверждение.
- Видео открывается внутри WePlay. Озвучка, серии, качество и субтитры доступны, когда их передаёт источник.

## Обновление

Начиная с 1.0.1, WePlay проверяет отдельный Android-канал в GitHub. Когда опубликован новый APK, рядом с «Поддержать» появляется кнопка **«Доступна новая версия»** с иконкой скачивания и цветным свечением.

1. Завершите просмотр и нажмите «Доступна новая версия».
2. Выберите «Скачать и обновить». Дождитесь загрузки APK.
3. Если Android откроет настройки установки неизвестных приложений, разрешите установку для **WePlay** и вернитесь назад.
4. Подтвердите обновление в системном установщике Android. После установки откройте WePlay.

Приложение проверяет размер, SHA256, название пакета, версию и сертификат подписи APK. Загрузка отменяется кнопкой «Отмена». Отказ от установки не удаляет скачанное обновление — его можно установить позже.

Для перехода с **1.0.0** один раз установите актуальный APK вручную поверх текущего приложения. История и избранное сохранятся. Не удаляйте приложение перед обновлением: удаление очистит его данные.

История с Samsung автоматически не переносится. Каналы обновления Tizen и Android независимы.

## Совместимость

Сборка проверена в эмуляторе Android TV 12: запуск, пульт, каталог, полноэкранное HLS-видео, меню качества и сохранение просмотра. Проверка на физическом Android TV пока не выполнена. Поддержка кодеков и доступность конкретных потоков зависят от устройства, версии WebView и источника.

Личные API-ключи из сборки Samsung в APK не включены. Доступные публичные каталоги и встроенный индекс изображений работают без них.

## Установка через ADB

Если отладка на устройстве уже включена:

```sh
adb install -r WePlay-AndroidTV-1.0.4.apk
adb shell am start -n app.weplay.tv/.MainActivity
```
