# Как установить WePlay на Android TV и Google TV

Нужен телевизор или приставка с **Android 8.0 или новее** и **Android System WebView**. Для каталога, видео и обновлений нужен интернет.

## 1. Скачайте APK

В таблице загрузок найдите строку **Android TV / Google TV** и нажмите **Скачать APK**. [Раздел «Скачать»](../README.md#скачать)

## 2. Передайте файл на телевизор

Скопируйте APK на флешку и подключите её к телевизору или приставке. Если флешки нет, отправьте файл с телефона или компьютера через приложение для передачи файлов на ТВ.

## 3. Установите WePlay

1. Откройте APK в файловом менеджере телевизора.
2. Если Android попросит разрешение на установку, дайте его файловому менеджеру и снова откройте APK.
3. Нажмите **Установить**. Затем откройте **WePlay** в списке приложений.

## Если установка не получается

- **Файла не видно.** Откройте флешку в файловом менеджере. Если передавали APK по сети, проверьте папку, куда приложение сохранило файл.
- **Android блокирует установку.** В настройках **Установка неизвестных приложений** разрешите установку для приложения, из которого открываете APK.
- **WePlay не открывается.** Проверьте, установлен ли **Android System WebView**, и обновите его, если доступна новая версия.

## Обновления

1. В WePlay нажмите **Доступна новая версия → Скачать и обновить**.
2. Если Android попросит разрешение на установку, дайте его приложению **WePlay** и вернитесь назад.
3. Подтвердите обновление в окне Android и снова откройте WePlay.

Если у вас WePlay **1.0.0**, один раз установите актуальный APK вручную поверх текущей версии. Так сохранятся история и избранное.

## Установка через ADB

<details>
<summary>Команда для установки с компьютера</summary>

Если телевизор уже подключён через ADB, откройте терминал в папке с APK. Подставьте имя скачанного файла и выполните команду.

```sh
adb install -r "WePlay-AndroidTV-X.Y.Z.apk"
```

Когда появится `Success`, откройте WePlay на телевизоре. [Как подключить устройство через ADB](https://developer.android.com/tools/adb)

</details>
