# Как установить WePlay на Samsung Tizen

Нужен Samsung Smart TV с **Tizen 5.5 или новее**. WePlay проверен на Samsung Q60T 2020 года. Подключите компьютер и телевизор к одной домашней сети. После установки компьютер можно выключить. Телевизору понадобится интернет для каталога, видео и обновлений.

## 1. Скачайте WePlay и Tizen Studio

- [Скачать WePlay-Tizen.wgt](https://github.com/bogdanhpk/WePlay/raw/refs/heads/main/downloads/WePlay-Tizen.wgt)
- [Установить Tizen Studio и расширения Samsung TV](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html)

В **Package Manager → Extension SDK** установите **TV Extensions** и **Samsung Certificate Extension**.

## 2. Включите режим разработчика на телевизоре

1. На компьютере откройте свойства активного сетевого подключения и запишите его **IPv4-адрес**. На Windows его также покажет команда `ipconfig`.
2. На телевизоре откройте **Home → Apps** и наберите **12345**. Если окно не появилось, сначала откройте настройки Apps и наберите код там. На пульте без цифр используйте экранную клавиатуру кнопки **123**.
3. Поставьте **Developer Mode → On**. В поле **Host PC IP** введите **IP компьютера**.
4. Нажмите **OK** и удерживайте кнопку питания на пульте до появления логотипа Samsung. После перезагрузки снова откройте **Apps**. Вверху должна появиться надпись **Develop Mode**.

[Инструкция Samsung с картинками](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html)

## 3. Установите WePlay с компьютера

На телевизоре откройте **Настройки → Сеть → Состояние сети → Настройки IP** и запишите **IP телевизора**. Раздел «Сеть» может находиться в «Общие» или «Подключение».

Откройте терминал в папке, куда скачали `WePlay-Tizen.wgt`. В командах `sdb connect` и `tizen install` замените `192.168.1.50` на **IP телевизора**. Порт `26101` оставьте как есть.

```sh
sdb connect 192.168.1.50:26101
sdb devices
tizen install -s 192.168.1.50:26101 -n WePlay-Tizen.wgt -- .
```

После `sdb devices` убедитесь, что напротив адреса телевизора стоит `device`. После установки откройте на телевизоре **Apps → WePlay**. Чтобы закрепить приложение, в меню WePlay выберите **Добавить на главный экран**.

## Если установка не получается

- **Телевизор не найден, `offline` или `Connection refused`.** Проверьте, что оба устройства в одной сети. В **Host PC IP** должен стоять IP компьютера, а в `sdb connect` — IP телевизора. Если **Develop Mode** не появился, отключите питание телевизора на 30 секунд, включите его и попробуйте снова.
- **Терминал не находит `sdb` или `tizen`.** В папке Tizen Studio найдите `sdb` в каталоге `tools`, а `tizen` — в `tools/ide/bin`. Запустите команды по полному пути к этим файлам или добавьте обе папки в `PATH`.
- **Телевизор отклонил подпись.** Соберите и подпишите пакет для своего телевизора по шагам ниже.
- **После обновления осталась старая иконка.** Удалите ярлык с главного экрана и снова закрепите WePlay из **Apps**.

## Обновления

Когда рядом с кнопкой **Поддержать** появится **Доступна новая версия**, выберите **Обновить сейчас**. WePlay перезапустится и сохранит историю и избранное. Проверка обновлений откладывается, пока идёт видео. Компьютер нужен, если новая версия меняет системную иконку, разрешения или загрузчик и требуется новый `.wgt`.

## Сборка из исходников

<details>
<summary>Как собрать и подписать пакет для своего телевизора</summary>

1. В Tizen Studio откройте **Tools → Device Manager** и подключите телевизор через **Remote Device Manager → +**. Введите IP телевизора и порт **26101**, затем включите **Connection**.
2. В **Tools → Certificate Manager** создайте профиль **Samsung → TV**. Войдите в аккаунт Samsung и при создании сертификата распространителя добавьте подключённый телевизор. Его идентификатор называется **DUID**. Если в меню телевизора в Device Manager есть **Permit to install applications**, выберите этот пункт. [Как создать сертификат Samsung TV](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/creating-certificates.html)
3. Установите Node.js 18 или новее. Скачайте исходники через **Code → Download ZIP**, распакуйте архив и откройте терминал в папке проекта.
4. Скопируйте `app/settings.example.js` в `app/settings.js`. Пример подходит для сборки без личных ключей. Если у вас есть свой токен источника или TMDB, храните его в локальном файле и не публикуйте его в GitHub. Для TMDB используйте поле `tmdbReadToken`.
5. Выполните команды ниже. Замените `WePlayTV` именем своего профиля сертификатов, а IP — адресом телевизора.

   ```sh
   node tools/build-shell.cjs app
   mkdir dist
   tizen package -t wgt -s WePlayTV -o dist -- app
   tizen install -s 192.168.1.50:26101 -n WePlay.wgt -- dist
   ```

   Если пакет в папке `dist` получил другое имя, укажите его после `-n`.

При повторной установке используйте тот же авторский сертификат, что и раньше. Чтобы сохранить локальную историю и избранное, оставьте текущую установку на телевизоре, пока разбираетесь с подписью.
