# Установка WePlay на Samsung TV

Приложение рассчитано на Samsung Smart TV с Tizen 5.5 и новее. Проверено на Samsung Q60T 2020 года с Tizen 5.5; совместимость остальных моделей требует проверки на конкретном телевизоре. Android TV, Google TV и старые Samsung без Tizen не подходят.

Для первой установки нужен компьютер. После установки WePlay работает самостоятельно: компьютер можно выключить. Для каталога, видео и получения новых версий телевизору нужен интернет.

## Что понадобится

- Телевизор и компьютер в одной домашней сети.
- [Tizen Studio с расширениями для Samsung TV](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html).
- Samsung Certificate Extension и профиль сертификатов для своего телевизора.
- Node.js 18 или новее, если вы собираете пакет из исходников.
- Подписанный установочный файл `.wgt`.

Скачайте [готовый WePlay-Tizen.wgt](https://github.com/bogdanhpk/WePlay-Tizen/releases/latest/download/WePlay-Tizen.wgt) из [последнего релиза](https://github.com/bogdanhpk/WePlay-Tizen/releases/latest). Архивы **Source code** содержат исходники, а установочный файл находится в **Assets**. Для готового `.wgt` раздел «Сборка из исходников» можно пропустить. Публичный установщик не содержит личных токенов владельца проекта.

## 1. Узнайте два IP-адреса

| Адрес | Куда его вводить |
|---|---|
| IP компьютера, например `192.168.1.10` | В поле **Host PC IP** на телевизоре |
| IP телевизора, например `192.168.1.50` | В Device Manager или команду `sdb connect` на компьютере |

Примеры ниже нужно заменить своими адресами. В Host PC IP вводится адрес компьютера, а не телевизора.

IP компьютера можно посмотреть в свойствах активного сетевого подключения. На Windows также подойдёт команда `ipconfig`: нужен IPv4-адрес подключения, через которое компьютер соединён с домашней сетью.

IP телевизора находится в настройках сети: **Настройки → Сеть → Состояние сети → Настройки IP**. На разных прошивках раздел сети может находиться в «Общие» или «Подключение».

## 2. Включите Developer Mode

1. Откройте **Home → Apps**. На новых моделях откройте настройки Apps.
2. Наберите **1 2 3 4 5** на пульте. Если цифровых кнопок нет, откройте экранную цифровую панель кнопкой `123`.
3. В появившемся окне поставьте **Developer Mode → On**.
4. В **Host PC IP** введите IP компьютера, например `192.168.1.10`.
5. Нажмите **OK** и перезагрузите телевизор. Удерживайте Power до появления логотипа Samsung. Если режим не применился, полностью выключите телевизор и отключите питание на 30 секунд.
6. Снова откройте Apps. Должна появиться надпись **Develop Mode**.

Если компьютер или его IP изменился, обновите Host PC IP и повторите перезагрузку. Для получения обновлений WePlay через интернет компьютер в дальнейшем не нужен.

## 3. Подключите телевизор к компьютеру

### Через Device Manager

1. В Tizen Studio откройте **Tools → Device Manager**.
2. Откройте **Remote Device Manager**, нажмите **+**.
3. Укажите произвольное имя, IP телевизора и порт **26101**.
4. Добавьте устройство и переключите **Connection → On**.

### Через терминал

Добавьте в PATH каталоги `<TIZEN_STUDIO>/tools` и `<TIZEN_STUDIO>/tools/ide/bin`, чтобы команды `sdb` и `tizen` были доступны из терминала. Вместо этого можно запускать их по полному пути к установленному SDK.

```sh
sdb connect 192.168.1.50:26101
sdb devices
```

В списке должна появиться строка с адресом телевизора и состоянием `device`, например:

```text
192.168.1.50:26101    device    <имя устройства>
```

Адрес `192.168.1.50` здесь — пример. Используйте фактический IP телевизора.

## 4. Сертификат, если он нужен вашему телевизору

Если готовый пакет устанавливается, создавать новый сертификат не нужно. Если телевизор отклоняет подпись или вы собираете приложение самостоятельно, подготовьте свой профиль Samsung TV, затем соберите и подпишите пакет из исходников по разделу 5.

В **Certificate Manager** создайте профиль **Samsung → TV**. Добавьте свой телевизор при настройке сертификата распространителя. Если мастер запрашивает DUID, получите его через подключённое устройство в Device Manager и добавьте в сертификат. В примерах ниже профиль называется `WePlayTV`.

Для Samsung-сертификата в Device Manager может потребоваться команда **Permit to install applications** в контекстном меню телевизора.

Для обновления уже установленного приложения используйте тот же авторский сертификат, что и при первой установке. Другой сертификат может не позволить установить пакет поверх существующего. Не удаляйте старую установку ради обновления: при удалении теряются локальные данные WePlay.

Пошаговый официальный процесс: [создание сертификатов Samsung TV](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/creating-certificates.html).

## 5. Сборка из исходников

Если подписанный `.wgt` у вас уже есть, пропустите этот раздел.

Скачайте ZIP репозитория кнопкой **Code → Download ZIP** и распакуйте его либо выполните:

```sh
git clone https://github.com/bogdanhpk/WePlay-Tizen.git
cd WePlay-Tizen
```

Создайте локальный `app/settings.js` из `app/settings.example.js`.

macOS / Linux:

```sh
cp app/settings.example.js app/settings.js
```

Windows PowerShell:

```powershell
Copy-Item app/settings.example.js app/settings.js
```

В примере поле `apiToken` пустое. Если у вас есть собственный токен для соответствующего источника, укажите его только в локальном `settings.js`. Другие доступные источники работают через общий каталог. Не добавляйте свои токены в GitHub.

Создайте резервный интерфейс и подпишите пакет своим профилем Tizen:

```sh
node tools/build-shell.cjs app
mkdir dist
tizen package -t wgt -s WePlayTV -o dist -- app
```

Замените `WePlayTV` названием своего профиля сертификатов. В каталоге `dist` должен появиться файл `WePlay.wgt`. Для сборки установщика закрытый ключ обновлений проекта не нужен: в приложении уже есть открытый ключ проверки.

## 6. Установите пакет

Для готового установщика откройте терминал в папке, куда скачан `WePlay-Tizen.wgt`, и выполните:

```sh
tizen install -s 192.168.1.50:26101 -n WePlay-Tizen.wgt -- .
```

Замените пример IP своим адресом телевизора. Если вы собрали пакет по предыдущему разделу, выполните из корня проекта:

```sh
tizen install -s 192.168.1.50:26101 -n WePlay.wgt -- dist
```

Если ваш файл называется `WePlay-Tizen.wgt`, укажите это имя в `-n`, а после `--` — папку, в которой лежит файл.

Дождитесь подтверждения успешной установки. Затем откройте **Apps → WePlay** на телевизоре. В Tizen Studio приложение также можно запустить как **Tizen Web Application**.

Не устанавливайте APK: Samsung Tizen использует пакет `.wgt`. Обычная установка этого приложения с USB не предусмотрена.

## 7. Добавьте WePlay на главный экран

В Apps найдите WePlay, откройте меню приложения и выберите **Добавить на главный экран**. Точное расположение действия зависит от прошивки.

Если после обновления Samsung показывает старую иконку, удалите только закреплённый ярлык с главной панели и добавьте WePlay заново из Apps. Само приложение удалять не нужно.

## Как дальше получать обновления

При запуске и затем периодически WePlay проверяет опубликованные выпуски в этом репозитории. Новая версия скачивается в фоне и сохраняется на телевизоре. Во время воспроизведения проверка и скачивание откладываются.

Когда обновление готово, рядом с **Поддержать** появится кнопка **Доступна новая версия** с иконкой скачивания и цветным свечением. Нажмите её, затем **Обновить сейчас**. WePlay перезапустится. **Позже** закрывает окно; загруженная версия также применяется при следующем запуске приложения.

История просмотра и избранное сохраняются. Если новая версия не запускается, загрузчик возвращается к предыдущей рабочей версии. Если интернета нет, используется сохранённая или комплектная версия; сам каталог и видео при этом могут быть недоступны без сети.

Разрешения Tizen, системная иконка и сам загрузчик обновляются установкой нового `.wgt`. Простое изменение исходников в GitHub не создаёт выпуск автоматически: владелец должен собрать и опубликовать подписанное обновление по инструкции в README.

## Если не получается

| Проблема | Что проверить |
|---|---|
| Телевизор не найден или `offline` | Телевизор включён, устройства в одной сети, в Host PC IP указан компьютер, после настройки выполнена полная перезагрузка |
| `Connection refused` | Developer Mode включён; адрес телевизора правильный; выполнена полная перезагрузка |
| Установка отклонена из-за сертификата | Профиль Samsung TV, DUID своего телевизора, разрешение установки и прежний авторский сертификат при обновлении |
| Пакет перестал устанавливаться после правки файлов | Заново соберите и подпишите `.wgt`; изменение уже подписанного пакета нарушает подпись |
| Кнопка новой версии не появляется | Телевизор подключён к интернету, просмотр завершён, опубликована версия новее текущей и с подходящей подписью |

Официальные инструкции Samsung: [подключение телевизора](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html), [командная строка](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/command-line-interface.html), [вопросы по установке и тестированию](https://developer.samsung.com/smarttv/develop/faq/application-testing.html).


## Обложки TMDB

TMDB дополняет обложки на главной, в списках и профилях медиа. Для подключения нужен собственный API Read Access Token из [настроек TMDB](https://www.themoviedb.org/settings/api). При сборке укажите его в локальном `app/settings.js`, в поле `tmdbReadToken`. Пример без ключей: `app/settings.example.js`. Не добавляйте личный токен и `settings.js` в GitHub или публичные сборки. Без токена работают резервные источники изображений.
