# Качество видео

В WePlay для Samsung Tizen, LG webOS и Android TV используется общий поиск доступных разрешений. Он проверяет источники выбранной озвучки. Студия, язык и серия сохраняются при переходе между источниками.

## Как выбрать максимальное качество

Откройте в плеере **Настройки → Качество**. Разрешения расположены от высокого к низкому. Выберите **2160p**, если этот вариант есть в списке. Кадр 3840 × 1600 также относится к 4K: чёрные полосы могут отсутствовать в самом видеофайле.

**Автоматически** ищет источник с наибольшим найденным разрешением. Проверка известных вариантов добавляет не более двух секунд к подготовке источника. Остальные источники проверяются после старта; если найден более высокий вариант той же озвучки, WePlay один раз переключается с сохранением позиции. Внутри HLS-потока качество адаптируется к соединению и возможностям устройства. Прямой MP4 воспроизводится в разрешении выбранного файла.

Ручной выбор сохраняется. Например, при выбранных 1080p приложение продолжает искать 4K для списка качества, но самостоятельно не меняет настройку на 2160p.

## Откуда берутся разрешения

- Для HLS WePlay читает реальные размеры вариантов из плейлиста.
- Для отдельных MP4 приложение читает ограниченные участки файла через HTTP Range и проверяет видеодорожку. Название ссылки вроде `mpeg4kUrl` не считается доказательством 4K: у источника встречаются перепутанные поля 2K и 4K.
- Данные из профиля заранее подготавливают поиск качества и ненадолго сохраняются в памяти. Неудачные или неполные проверки не блокируют повторную попытку.
- Меню дополняется по мере получения результатов. При выборе качества сохраняются озвучка, серия, позиция и пауза.

4K появится только там, где доступный источник действительно предоставляет такой вариант. Поддержка кодеков и плавность воспроизведения зависят от телевизора.

## Проверка выпуска

По данным проверенного источника на 22 ноября 2026 года:

| Медиа | Максимальное проверенное разрешение |
| --- | --- |
| Матрица | 2160p / 4K |
| Шрэк | 2160p / 4K |
| Холодное сердце | 1080p |
| История игрушек | 1080p |

Это результаты конкретного источника и проверенных озвучек. В другом источнике варианты могут отличаться.

Автоматические тесты:

```sh
node tools/test-quality-probe.cjs
node tools/test-playback-quality.cjs
node tools/test-all-voices.cjs
```

В Chromium проверены меню и переходы HLS/MP4 с адаптерами Android, Tizen и webOS, в том числе Samsung AVPlay, ручное качество на паузе и автоматическое повышение качества. Эти проверки эмулируют платформенные API и не заменяют проверку кодеков на каждом телевизоре.

Для разработчиков: [многовариантные HLS-плейлисты](https://developer.apple.com/streaming/hls-authoring-specification-for-apple-devices.html), [состояния и информация о потоке Samsung AVPlay](https://developer.samsung.com/smarttv/develop/api-references/samsung-product-api-references/avplay-api.html).
