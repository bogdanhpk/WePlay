# Пропуск заставки

Во время заставки сериала справа появляется кнопка **«Пропустить заставку»**. Она сразу получает фокус: нажмите OK, чтобы перейти к концу заставки. Приложение само не перематывает видео.

«Назад» скрывает кнопку и оставляет просмотр на текущем месте. Стрелка вверх переводит фокус на шкалу времени, вниз — на кнопки плеера. Перемотка назад до начала заставки позволяет пропустить её снова. Пауза сохраняется при пропуске.

Карточка следующей серии тоже получает фокус при появлении. Действующая логика автоперехода не меняется: отсчёт начинается на отмеченных титрах или после завершения серии.

## Откуда берутся отметки

Приоритет имеют отметки конкретного воспроизводимого источника с явно указанными единицами времени. При их отсутствии WePlay использует IMDb ID сериала, номер сезона и серии: сначала [SkipDB](https://skipdb.tv/docs), затем [IntroDB](https://api.introdb.app/reference/get-segments/).

SkipDB получает длительность текущей копии. Подходят точные совпадения или консервативно сдвинутые отметки при разнице не больше 15 секунд. Копии с явно несовпадающим монтажом исключаются из автоматического подбора отметки. IntroDB хранит общие отметки серии, которые могут различаться у разных монтажей.

Без отметки, при низкой уверенности, несовпадении идентификаторов или ошибке сервиса кнопка не показывается. Перемотка с пульта остаётся доступной. Отметки есть не для всех сериалов и серий.

Запросы начинаются после старта видео и не задерживают воспроизведение. Ответ ограничен 32 КиБ, тайм-аут каждого сервиса — 3,5 секунды. Отметки временно кешируются на устройстве с учётом серии и длительности. Закрытие плеера отменяет запросы. Приложение не отправляет отметки в базы.

Общий модуль используется в Android TV / Google TV, Samsung Tizen и LG webOS. Для проверки данных: `node tools/test-skip-intro.cjs`.

## Атрибуция

Contains data from IntroDB (introdb.app), available under the ODbL. [Лицензия и данные](https://api.introdb.app/open-data/).

Intro timestamps: SkipDB (skipdb.tv), ODbL 1.0 + reciprocity. [API и условия использования](https://skipdb.tv/docs).
