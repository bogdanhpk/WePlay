# Интерфейс WePlay 1.22.39

- Кнопка «Поддержать» приведена к стандартным размерам кнопок шапки: высота 64, текст 24, иконка 28 пикселей в макете 1920×1080.
- Размер одинаков на главной, в профиле и разделах. Кнопка обновления рядом использует тот же размер.

# Интерфейс WePlay 1.22.38

- Скрыты вертикальные и горизонтальные полосы прокрутки на всех страницах, в каруселях, поиске и меню плеера.
- Прокрутка и перемещение фокуса с пульта сохранены.

# Интерфейс WePlay 1.22.37

- Высота больших обложек на главной и в профиле уменьшена до 880 пикселей в макете 1920×1080.
- На первом экране снова видно начало каталогов, сезонов или информации о фильме.
- Обложки сохраняют заполнение по ширине; общий слой ресурсов остаётся без изменений.

# Интерфейс WePlay 1.22.36

- Главная, каталоги, поиск, избранное и профили используют общий пакет ресурсов каждого медиа.
- Большой фон и горизонтальное превью относятся к одной выбранной обложке, различается только размер.
- При отказе оригинала сохраняется превью того же кадра.
- Список актёров и их изображения хранятся в общем кеше; повторные страницы используют готовые ресурсы.
- Убран независимый выбор источников изображений внутри страниц.
- Системная оранжевая иконка сохранена.

# Пакет WePlay 1.22.35 / интерфейс 1.22.34

- Возвращена прежняя системная иконка: оранжевый фон и белый логотип WePlay.
- Изменение иконки устанавливается через WGT; обновление интерфейса остаётся 1.22.34.

# Интерфейс WePlay 1.22.34

- Добавлен резервный индекс TMDB для стандартных подборок и нескольких контрольных фильмов: 45 совпадений, 44 с широкими фонами.
- Эти обложки работают при недоступном API TMDB на телевизоре; изображения загружаются с CDN без ключей.
- История просмотра и избранное не использовались при подготовке индекса.
- Прямой TMDB API и остальные источники остаются для медиа за пределами индекса.

# Интерфейс WePlay 1.22.33

- TMDB API подключается с личным токеном, который хранится только в локальной конфигурации.
- Горизонтальные обложки TMDB используются на главной, в профилях и в небольших карточках.
- Для списков загружаются уменьшенные изображения, для больших фонов — оригиналы.
- Совпадение проверяется по внешним ID либо точному названию, году и типу медиа.
- При медленном ответе карточки используют резервную обложку из каталога.
- Добавлено указание TMDB в информации о медиа.

# Интерфейс WePlay 1.22.32

- Фон карусели на главной заполняет весь экран, включая запасные постеры.
- Широкие промоизображения имеют приоритет перед быстрым вертикальным постером; проверяются пропорции и разрешение.
- Устаревший выбор постеров для большого фона обновляется; при отсутствии широкого кадра используется мягкий размытый фон.
- Проверка обновлений во время работы приложения выполняется раз в минуту.
- Во время просмотра и в фоне проверка и загрузка отложены.

# Интерфейс WePlay 1.22.31

- Обложка в профиле фильма или сериала заполняет весь экран.
- Запасной постер также заполняет фон, без небольшой картинки справа.
- Пропорции изображений сохраняются, края обрезаются по размеру экрана.

# WePlay 1.22.29 / интерфейс 1.22.30

- Подписанные обновления интерфейса и логики из GitHub с сохранением на телевизоре.
- Активация при следующем запуске, без перезапуска во время просмотра.
- Автоматический возврат к предыдущей версии при ошибке запуска.
- Проверка ECDSA P-256 и SHA-256; повреждённые и несовместимые выпуски не запускаются.
- История просмотра, избранное и локальные настройки сохраняются.
- Исправлен подбор изображений для «В пути» и других фильмов и сериалов.
- Убрана заглушка Кинопоиска при отсутствии постера.
- TVmaze используется первым для промофонов и фото актёров сериалов и мультсериалов; для фильмов и недостающих изображений — TMDB/Cinemeta.
