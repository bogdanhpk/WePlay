# Интерфейс WePlay 1.22.31

- Обложка в профиле фильма или сериала заполняет весь экран.
- Запасной постер также заполняет фон, без небольшой картинки справа.
- Пропорции изображений сохраняются, края обрезаются по размеру экрана.

# WePlay 1.22.29 / интерфейс 1.22.30

- Подписанные обновления интерфейса и логики из GitHub с сохранением на телевизоре.
- Активация при следующем запуске, без перезапуска во время просмотра.
- Автоматический возврат к предыдущей версии при ошибке запуска.
- Проверка ECDSA P-256 и SHA-256; повреждённые и несовместимые выпуски не запускаются.
- История просмотра, избранное и локальные настройки сохраняются.
- Исправлен подбор изображений для «В пути» и других фильмов и сериалов.
- Убрана заглушка Кинопоиска при отсутствии постера.
- TVmaze используется первым для промофонов и фото актёров сериалов и мультсериалов; для фильмов и недостающих изображений — TMDB/Cinemeta.
